## 行為差異與取捨

- 以**實際起點**查詢及快取，移除原本三位小數共用格子。新快取鍵加 `origin` 前綴，舊格子資料自然失效。這解決格心偏移漏查，但鄰近不同位置的命中率會下降；沒有增加每次 NearBy 端點數或超過 TDX 的 1000m 上限。
- TDX 輪替保留既有每把五次／分鐘策略；auth 網路異常可退下一把，失效 token 不留到下一分鐘反覆失敗。
- NTPC 最大二十頁是安全上限；若第二十頁仍滿載，回未知而非快取不完整名單。擴大上限或支援更多資料需另依來源規格評估。
- 群組沒有 userId 時不再建立以 groupId／roomId 計算的「個人」額度。符合 `docs/setup.md` 原有契約；公共預算仍限制這些查詢。
- 新舊使用者的個人計數寫入失敗均不放行，並回暫時無法記錄使用次數的說明；不以個人額度用盡誤導使用者。
- 保留端點種類、HTTP 狀態、數量與耗時日誌。正式查詢資料不作公開 fixture；fixture 座標、名稱、身分與 key 都是固定合成值。
